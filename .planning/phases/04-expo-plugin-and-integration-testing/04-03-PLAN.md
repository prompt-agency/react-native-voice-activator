**Part A: Create `example/src/screens/EnrollmentScreen.tsx`**

Follow the exact same style as `WakeWordScreen.tsx` — same imports, same `ScrollView` + section pattern, same `Btn` and `C` token usage, same `StyleSheet.create` at bottom.

The screen demonstrates the full enrollment round-trip per D-10:

State:
- `sampleCount: number` (0-3, how many samples enrolled)
- `userId: string` (hardcoded to `'demo-user'` for simplicity)
- `exportedData: string | null` (JSON stringified enrollment data)
- `status: string` (displays current state/last action result)
- `isRecording: boolean` (for button state)

Sections (using the same SectionCard/section pattern as other screens):

**Section 1 — "Enroll Speaker"**
- Display: "Samples: {sampleCount}/3"
- Button: "Record Sample" — On press:
  - Create a dummy ArrayBuffer (512 bytes of zeros) for the demo since mic capture requires device
  - Call `voiceActivator.enrollSpeaker('demo-user', dummyBuffer, 16000)`
  - Increment `sampleCount`
  - Update `status` to `"Sample {n} enrolled"`
  - Wrap in try/catch, show error in status on failure
- Note text below button: "On real device: captures mic audio. In simulator: uses dummy data."

**Section 2 — "Export & Import"**
- Button: "Export Enrollment" — On press:
  - Call `const data = await voiceActivator.exportEnrollment()`
  - Set `exportedData` to `JSON.stringify(data, null, 2)`
  - Update `status` to `"Exported {n} speaker(s)"`
- Button: "Simulate Restart" (disabled if `exportedData` is null) — On press:
  - Call `await voiceActivator.clearEnrollment()`
  - Parse `exportedData` back and call `await voiceActivator.importEnrollment(JSON.parse(exportedData))`
  - Update `status` to `"Cleared and re-imported enrollment"`
- Button: "Clear All" — On press:
  - Call `await voiceActivator.clearEnrollment()`
  - Reset `sampleCount` to 0, `exportedData` to null
  - Update `status` to `"Enrollment cleared"`

**Section 3 — "Status"**
- Display current `status` string in a Text with `C.textMuted` style
- If `exportedData` is set, show a truncated preview (first 100 chars + "...")

Import `voiceActivator` from `react-native-voice-activator`.
