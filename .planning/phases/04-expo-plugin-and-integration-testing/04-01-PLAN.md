4. Define a helper function:
```typescript
function resolveModelPath(projectRoot: string, rawPath: string, fieldName: string): string {
  const resolved = path.isAbsolute(rawPath) ? rawPath : path.resolve(projectRoot, rawPath);
  if (!existsSync(resolved)) {
    throw new Error(`[${PACKAGE_NAME}] ${fieldName}: configured path does not exist: ${resolved}`);
  }
  return resolved;
}
```

5. Define model field config:
```typescript
const MODEL_FIELDS = [
  { field: 'speakerModelPath' as const, subdir: 'SherpaOnnxSpeaker' },
  { field: 'denoiserModelPath' as const, subdir: 'SherpaOnnxDenoiser' },
] as const;
```

6. Export `withModelAssets` as a `ConfigPlugin<Pick<VoiceActivatorPluginProps, 'speakerModelPath' | 'denoiserModelPath'>>`:

**iOS file copy** (`withDangerousMod(config, ['ios', async (modConfig) => { ... }])`):
- Get `projectRoot` from `modConfig.modRequest.projectRoot`
- Get `platformProjectRoot` from `modConfig.modRequest.platformProjectRoot`
- Get `appName` via `modConfig.modRequest.projectName ?? 'App'`
- Iterate over MODEL_FIELDS
- For each: if `props[field]` is truthy, call `resolveModelPath(projectRoot, props[field], field)` to get `srcPath`
- Construct `destDir = path.join(platformProjectRoot, appName, subdir)`
- `mkdirSync(destDir, { recursive: true })`
- `copyFileSync(srcPath, path.join(destDir, path.basename(srcPath)))`
- Return `modConfig`

**iOS Xcode project registration** (`withXcodeProject(config, (modConfig) => { ... })`):
- This is CRITICAL — without it, copied files won't be in the .app bundle
- Get `xcodeProject` from `modConfig.modResults`
- Get `projectRoot` and `appName` same way
- For each MODEL_FIELDS entry where `props[field]` is truthy:
  - Construct `relativePath = path.join(appName, subdir, path.basename(props[field]))`
  - Call `xcodeProject.addResourceFile(relativePath, { target: xcodeProject.getFirstTarget().uuid })`
  - If the file is not already in a PBXGroup for the subdir, create one
- Return `modConfig`

**Android mod** (`withDangerousMod(config, ['android', async (modConfig) => { ... }])`):
- Get `projectRoot` from `modConfig.modRequest.projectRoot`
- Get `platformProjectRoot` from `modConfig.modRequest.platformProjectRoot`
- Iterate over MODEL_FIELDS (only use `field`, not `subdir` — Android uses flat assets dir)
- For each: if `props[field]` is truthy, call `resolveModelPath(projectRoot, props[field], field)`
- Construct `destDir = path.join(platformProjectRoot, 'app', 'src', 'main', 'assets', 'voice-activator-sherpa-onnx')`
- `mkdirSync(destDir, { recursive: true })`
- `copyFileSync(srcPath, path.join(destDir, path.basename(srcPath)))`
- Return `modConfig`

Return final `config`.

Per D-01: flat string fields. Per D-02: resolve relative to projectRoot. Per D-03: independently optional (skip if not set). Per D-04: hard-fail throw on missing file. Per D-05: iOS uses SherpaOnnxSpeaker/SherpaOnnxDenoiser subdirs, Android uses voice-activator-sherpa-onnx.

IMPORTANT (per RESEARCH.md Open Question 3): iOS requires BOTH file copy via `withDangerousMod` AND `.pbxproj` registration via `withXcodeProject` + `addResourceFile`. Without the Xcode project registration, files copied to `ios/<AppName>/` will NOT be included in the `.app` bundle's Copy Bundle Resources phase. Android assets from `android/app/src/main/assets/` are auto-included by Gradle — no extra step needed.
